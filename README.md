# 💻 C++ Object-Oriented Programming

A collection of C++ programs, examples, and practice problems focused on understanding and implementing **Object-Oriented Programming (OOP)** concepts.

This repository contains programs written while learning C++ and exploring how OOP concepts can be used to design structured, reusable, and maintainable programs.

---

## 📖 About

Object-Oriented Programming is a programming approach that organizes programs around **objects and classes** rather than only functions and logic.

This repository is mainly focused on learning the core concepts of OOP in C++ through practical programs and problem-solving.

The programs demonstrate concepts ranging from basic classes and objects to more advanced topics such as inheritance, polymorphism, virtual functions, operator overloading, and templates.

---

## 📚 Concepts Covered

### 1. Classes and Objects

Programs demonstrating:

- Creating classes
- Creating and using objects
- Data members
- Member functions
- Accessing class members
- Public, private, and protected members

### 2. Constructors and Destructors

Examples covering:

- Default constructors
- Parameterized constructors
- Copy constructors
- Constructor overloading
- Destructors
- Object initialization

### 3. Encapsulation

Programs demonstrating how data and the functions that operate on that data can be combined within a class.

Topics include:

- Data hiding
- Access specifiers
- Getters and setters
- Private data members

### 4. Abstraction

Examples showing how implementation details can be hidden while exposing only the required functionality.

Topics include:

- Abstract classes
- Pure virtual functions
- Interfaces using classes

### 5. Inheritance

Programs demonstrating different types of inheritance:

- Single inheritance
- Multiple inheritance
- Multilevel inheritance
- Hierarchical inheritance
- Hybrid inheritance

### 6. Polymorphism

Programs covering both compile-time and runtime polymorphism.

Topics include:

- Function overloading
- Operator overloading
- Function overriding
- Virtual functions
- Runtime polymorphism

### 7. Operator Overloading

Examples of redefining operators to work with user-defined objects.

Some examples include:

- Unary operator overloading
- Binary operator overloading
- Arithmetic operators
- Comparison operators

### 8. Friend Functions

Programs demonstrating:

- Friend functions
- Friend classes
- Accessing private and protected members

### 9. Static Members

Examples covering:

- Static data members
- Static member functions
- Sharing data between objects

### 10. `this` Pointer

Programs demonstrating the use of the `this` pointer for:

- Referring to the current object
- Resolving naming conflicts
- Returning the current object

### 11. Virtual Functions

Examples demonstrating:

- Virtual functions
- Function overriding
- Dynamic binding
- Runtime polymorphism

### 12. Exception Handling

Programs covering:

- `try`
- `catch`
- `throw`
- Handling runtime errors
- Multiple exception handlers

### 13. File Handling

Programs demonstrating how C++ can be used to work with files.

Topics include:

- Creating files
- Reading from files
- Writing to files
- Appending data
- File streams

### 14. Templates

Examples covering generic programming using:

- Function templates
- Class templates
- Generic data types
